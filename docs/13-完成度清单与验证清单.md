## 三、验证清单（快速自检）

```bash
# 进入项目根目录
cd FuxiPass

# 1) 编译 + 测试 + 静态检查（应全绿）
cargo test --workspace              # 188 项通过，0 失败，退出码 0
cargo clippy --all-targets -- -D warnings   # 0 警告
cargo fmt --all -- --check          # 通过

# 2) 环境就绪体检
bash scripts/check-dev-ready.sh      # 17 项全过，退出码 0

# 3) 运行（正式库 + 找回服务）
./target/debug/vault_web --db ~/FuxiPassVault/fuxipass.vault.db --port 8787 \
  --recovery-service http://127.0.0.1:8799 --recovery-token-file ~/FuxiPassVault/recovery.token
./target/debug/recovery_service --port 8799 --db ~/FuxiPassVault/recovery.db \
  --smtp-url smtps://smtp.qq.com:465 --smtp-user 你的QQ@qq.com --smtp-pass-file ~/FuxiPassVault/smtp.pass

# 4) 健康检查
curl -s http://127.0.0.1:8799/v1/health        # bindings: 1
curl -s http://127.0.0.1:8787/api/status       # version == 仓库 HEAD

# 5) 安全自检（应全 401）
curl -s -o /dev/null -w "%{http_code}\n" -H "Host: evil.example.com" http://127.0.0.1:8787/api/status   # 401
curl -s -o /dev/null -w "%{http_code}\n" -X POST http://127.0.0.1:8799/v1/recovery/bind \
  -H 'Content-Type: application/json' -d '{"contact_hash":"x","contact_type":"email","recoverywrap":"y"}'   # 401（无令牌）
```

## 四、安全审计对账表（每个发现 → 修复 → 验证）

| CWE | 发现 | 修复 | 验证 | 提交 |
| :-- | :-- | :-- | :-- | :-- |
| CWE-345 (host) | DNS rebinding / CSRF 直写本机服务 | `guard_local_origin`（Host/Origin/Sec-Fetch） | 伪造 Host 401 | `1f5bdf8` |
| CWE-306/862 | 找回服务 bind 零认证 → 绑定劫持 | 令牌鉴权 + **默认开启** + 恒定时间比较 | 无令牌 401 | `1f5bdf8` |
| CWE-639 | challenge 响应差异可枚举账号 | 统一 200 + 诱饵挑战 + 限流先于绑定判断 | 未绑定 200 | `e9de486` |
| CWE-770 | Web 层验证码无限流 | `check_recovery_rate_limit`（3/10min） | 第 3 次 429 | `e9de486` |
| CWE-93 | SMTP To: 头注入面 | `validate_address`（拒空白/CRLF/尖括号） | 注入用例 err | `e9de486` |
| CWE-377 | 邮件临时文件 0644 + 可预测名 | 创建即 0600 + O_EXCL + CSPRNG 名 | 权限测试 | `1f5bdf8` |
| CWE-400 | KDF 无上界 → OOM | `validate` 加上界（≤1GiB/16/16） | 超大参数 err | `1f5bdf8` |
| CWE-208 | 令牌/验证码比较时序 | 恒定时间比较 | — | `e9de486` |
| CWE-330 | 验证码模偏 / 请求 ID 可预测 | 拒绝采样 + CSPRNG | — | `e9de486` |
| CWE-521 | 备份口令下限 8 | 提升至 12 | — | `e9de486` |
| — | 请求体无上限 | 8MiB / 1MiB 上限 | — | `e9de486` |

> **审计确认的良好性质（非缺陷）**：FFI 边界健壮（panic 拦截/Miri）、SQLite 篡改检测有效、
