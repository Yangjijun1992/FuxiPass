## 2. 架构

```
┌───────────────────────────────────────────────┐
│ Flutter UI (Dart)                             │
│  ├─ 解锁页 / 列表页 / 详情页 / 设置页          │
│  └─ VaultBackend (抽象接口)                    │
└──────────────┬────────────────────────────────┘
               │  dart:ffi  (C ABI)
┌──────────────┴────────────────────────────────┐
│ vault_ffi (Rust cdylib/staticlib)             │
│  ├─ 句柄管理（不透明指针）                      │
│  ├─ JSON 字符串进出（避免复杂结构体封送）        │
│  └─ panic 捕获（catch_unwind，禁止跨 FFI 展开）  │
└──────────────┬────────────────────────────────┘
               │  纯 Rust 调用（无 FFI）
┌──────────────┴────────────────────────────────┐
│ vault_store  →  security_core                 │
│  （字段级加密 + SQLite + 密钥体系）             │
└───────────────────────────────────────────────┘
```

**设计要点**
- **不透明句柄**：Dart 侧只持有 `*mut Handle`，内部是 `Vault`；不可伪造。
- **JSON 进出**：字符串跨边界，避免结构体布局/对齐问题（Category 6）。
- **panic 必须捕获**：`extern "C"` 中 panic 跨边界是 UB（Category 14），所有入口都用 `catch_unwind` 包裹。
- **所有权明确**：返回值由 Rust 分配（`CString::into_raw`），Dart 必须调用 `fuxipass_string_free` 释放（Category 12）。

## 3. FFI 契约（C ABI）

> 所有函数均 `#[no_mangle] pub extern "C"`；字符串为 NUL 结尾 UTF-8；错误通过统一 JSON 返回。

| 函数 | 签名（C） | 说明 |
| :-- | :-- | :-- |
| `fuxipass_unlock` | `*mut FuxiHandle (db_path: *const c_char, master_password: *const c_char)` | 解锁；失败返回 NULL，错误经 `fuxipass_last_error` |
| `fuxipass_lock` | `void (h: *mut FuxiHandle)` | 释放句柄（Drop 时密钥 zeroize） |
| `fuxipass_list_accounts` | `*mut c_char (h: *mut FuxiHandle)` | 返回 `AccountSummary[]` 的 JSON |
| `fuxipass_get_account` | `*mut c_char (h: *mut FuxiHandle, id: *const c_char)` | `AccountDetail` JSON |
| `fuxipass_create_account` | `c_int (h: *mut FuxiHandle, input_json: *const c_char)` | 返回 0=成功 |
| `fuxipass_update_account` | `c_int (h: *mut FuxiHandle, id: *const c_char, input_json: *const c_char)` | |
| `fuxipass_delete_account` | `c_int (h: *mut FuxiHandle, id: *const c_char)` | |
| `fuxipass_reveal_secret` | `*mut c_char (h: *mut FuxiHandle, id: *const c_char, field_type: *const c_char, master_password: *const c_char)` | **二次验证**；返回 `{"value":"..."}` |
| `fuxipass_lock_status` | `*mut c_char (db_path: *const c_char)` | `LockStatus` JSON（锁定剩余秒数） |
| `fuxipass_string_free` | `void (s: *mut c_char)` | 释放 Rust 分配的字符串 |
| `fuxipass_last_error` | `*mut c_char ()` | 最近一次错误的 JSON（线程局部） |

**错误 JSON**：`{"code":"...","message":"..."}`，`code` 取值与 `ApiError` 一致。

## 4. 平台能力映射（PRD 功能 → 原生 API）

| PRD 功能 | Android | iOS |
| :-- | :-- | :-- |
| 生物识别解锁 | `BiometricPrompt` + `setUserAuthenticationRequired` | `LocalAuthentication`（`.deviceOwnerAuthentication`） |
| 硬件密钥存储 | `AndroidKeyStore`（StrongBox 优先） | `Keychain`（`kSecAttrAccessibleWhenUnlockedThisDeviceOnly`） |
| 防截图 / 防录屏 | `WindowManager.LayoutParams.FLAG_SECURE` | ❌ 无对等能力（仅能做前台检测；须如实告知，见 ADR-009） |
| 自动填充 | `AutofillService` | `ASCredentialProviderViewController` |
| 登录页抓取 | ❌ 不用无障碍（合规风险，见 ADR-007）→ 改为**用户主动导入**为主 | 同左（无系统级抓取能力） |
| 剪贴板自清空 | `ClipboardManager` + 定时清空 | `UIPasteboard` + 定时清空 |
| 目录隔离 | App 私有目录 + `EncryptedFile` 可选 | `Application Support`（默认 iCloud 备份排除） |

> **注**：`vault_ffi` 只暴露纯数据能力；平台能力由 Dart 侧通过 `MethodChannel` 调用原生实现。

## 6. 门禁与验证计划

### 6.1 UB 门禁 ✅ 已通过

```bash
rustup toolchain install nightly --profile minimal --component miri,rust-src
cargo +nightly miri test -p vault_ffi --test ffi_safety        # Level 1 ✅
MIRIFLAGS="-Zmiri-strict-provenance -Zmiri-symbolic-alignment-check" ...   # Level 2 ✅
MIRIFLAGS="... -Zmiri-preemption-rate=0.1 -Zmiri-disable-isolation" ...    # Level 3 ✅
MIRIFLAGS="-Zmiri-tree-borrows ..." ...                                    # Level 4 ✅
```

结果：**8 项边界测试在四个严格级别下全部通过，无未定义行为**。
审计中另发现并修复一处**安全缺陷**：`reveal_secret` 曾漏做二次验证（详见审计报告 §5）。

### 6.2 FFI 测试计划（实现后）

| 用例 | 目的 |
| :-- | :-- |
| 空指针 / 非法 UTF-8 入参 | Category 5/8：边界校验不 panic |
| 错误主密码 | 返回 NULL + 正确错误 JSON |
| 句柄重复释放 | Category 12：`Box::from_raw` 只调用一次 |
| 跨线程调用 | Category 9：句柄 `Send` 约束 |
| 返回字符串释放 | Category 12：`CString::from_raw` 配对 |
| panic 注入 | Category 14：`catch_unwind` 拦截，不跨边界展开 |

### 6.3 构建门禁

| 平台 | 需要 | 产物 |
| :-- | :-- | :-- |
| Android | Flutter SDK + Android SDK/NDK + Rust target `aarch64-linux-android` | `libvault_ffi.so`（4 ABI） |
| iOS | Xcode + Rust target `aarch64-apple-ios` | `libvault_ffi.a`（静态链接） |
