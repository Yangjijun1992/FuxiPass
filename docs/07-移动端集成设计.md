## 2. 架构

```
┌───────────────────────────────────────────────┐
│ Flutter UI (Dart)                             │
│  ├─ 解锁页 / 列表页 / 详情页 / 设置页          │
│  └─ VaultBackend (抽象接口)                    │
└──────────────┬────────────────────────────────┘
               │  dart:ffi  (C ABI)
┌──────────────┴────────────────────────────────┐
│ vault_ffi (Rust cdylib/staticlib)             │
│  ├─ 句柄管理（不透明指针）                      │
│  ├─ JSON 字符串进出（避免复杂结构体封送）        │
│  └─ panic 捕获（catch_unwind，禁止跨 FFI 展开）  │
└──────────────┬────────────────────────────────┘
               │  纯 Rust 调用（无 FFI）
┌──────────────┴────────────────────────────────┐
│ vault_store  →  security_core                 │
│  （字段级加密 + SQLite + 密钥体系）             │
└───────────────────────────────────────────────┘
```

**设计要点**
- **不透明句柄**：Dart 侧只持有 `*mut Handle`，内部是 `Vault`；不可伪造。
- **JSON 进出**：字符串跨边界，避免结构体布局/对齐问题（Category 6）。
- **panic 必须捕获**：`extern "C"` 中 panic 跨边界是 UB（Category 14），所有入口都用 `catch_unwind` 包裹。
- **所有权明确**：返回值由 Rust 分配（`CString::into_raw`），Dart 必须调用 `fuxipass_string_free` 释放（Category 12）。

## 3. FFI 契约（C ABI）

> 所有函数均 `#[no_mangle] pub extern "C"`；字符串为 NUL 结尾 UTF-8；错误通过统一 JSON 返回。

| 函数 | 签名（C） | 说明 |
| :-- | :-- | :-- |
| `fuxipass_unlock` | `*mut FuxiHandle (db_path: *const c_char, master_password: *const c_char)` | 解锁；失败返回 NULL，错误经 `fuxipass_last_error` |
| `fuxipass_lock` | `void (h: *mut FuxiHandle)` | 释放句柄（Drop 时密钥 zeroize） |
| `fuxipass_list_accounts` | `*mut c_char (h: *mut FuxiHandle)` | 返回 `AccountSummary[]` 的 JSON |
| `fuxipass_get_account` | `*mut c_char (h: *mut FuxiHandle, id: *const c_char)` | `AccountDetail` JSON |
| `fuxipass_create_account` | `c_int (h: *mut FuxiHandle, input_json: *const c_char)` | 返回 0=成功 |
| `fuxipass_update_account` | `c_int (h: *mut FuxiHandle, id: *const c_char, input_json: *const c_char)` | |
| `fuxipass_delete_account` | `c_int (h: *mut FuxiHandle, id: *const c_char)` | |
| `fuxipass_reveal_secret` | `*mut c_char (h: *mut FuxiHandle, id: *const c_char, field_type: *const c_char, master_password: *const c_char)` | **二次验证**；返回 `{"value":"..."}` |
| `fuxipass_lock_status` | `*mut c_char (db_path: *const c_char)` | `LockStatus` JSON（锁定剩余秒数） |
| `fuxipass_string_free` | `void (s: *mut c_char)` | 释放 Rust 分配的字符串 |
| `fuxipass_last_error` | `*mut c_char ()` | 最近一次错误的 JSON（线程局部） |

**错误 JSON**：`{"code":"...","message":"..."}`，`code` 取值与 `ApiError` 一致。

## 4. 平台能力映射（PRD 功能 → 原生 API）

| PRD 功能 | Android | iOS |
| :-- | :-- | :-- |
| 生物识别解锁 | `BiometricPrompt` + `setUserAuthenticationRequired` | `LocalAuthentication`（`.deviceOwnerAuthentication`） |
| 硬件密钥存储 | `AndroidKeyStore`（StrongBox 优先） | `Keychain`（`kSecAttrAccessibleWhenUnlockedThisDeviceOnly`） |
| 防截图 / 防录屏 | `WindowManager.LayoutParams.FLAG_SECURE` | ❌ 无对等能力（仅能做前台检测；须如实告知，见 ADR-009） |
| 自动填充 | `AutofillService` | `ASCredentialProviderViewController` |
| 登录页抓取 | ❌ 不用无障碍（合规风险，见 ADR-007）→ 改为**用户主动导入**为主 | 同左（无系统级抓取能力） |
| 剪贴板自清空 | `ClipboardManager` + 定时清空 | `UIPasteboard` + 定时清空 |
| 目录隔离 | App 私有目录 + `EncryptedFile` 可选 | `Application Support`（默认 iCloud 备份排除） |

> **注**：`vault_ffi` 只暴露纯数据能力；平台能力由 Dart 侧通过 `MethodChannel` 调用原生实现。

## 9. 平台适配层实现契约（T1.4）

Rust 侧已实现**平台无关抽象**（`vault_store::secure_store`），移动端只需按下列契约提供原生实现。

### 9.1 Rust 侧抽象（已完成并通过测试）

```rust
pub trait SecureStore: Send + Sync {
    fn store(&self, id: &str, secret: &[u8]) -> Result<(), PlatformError>;
    fn load(&self, id: &str) -> Result<Option<Vec<u8>>, PlatformError>;
    fn delete(&self, id: &str) -> Result<(), PlatformError>;
}
```

提供三种实现：
| 实现 | 用途 | 保护级别 |
| :-- | :-- | :-- |
| `MemorySecureStore` | 测试 | 进程内存 |
| `FileSecureStore` | PC 原型兜底 | ⚠️ **无硬件保护**（已做路径穿越防护） |
| `CallbackSecureStore` | 移动端桥接 | 取决于原生实现（Keystore/Keychain） |

**安全契约**：该存储**只放 `AccountKey`**（`ACCOUNT_KEY_ID`），
绝不放主密码、DEK、恢复密钥或任何可直接解密数据的凭据。

### 9.2 会话策略（已完成并通过测试）

`vault_store::session::Session` 实现 PRD §2.1/§3.4.2：

| 行为 | 规则 |
| :-- | :-- |
| 生物识别解锁 | 仅在上次**主密码验证后 24 小时内**有效，超时返回 `MasterReauthRequired` |
| 主密码解锁 | 重置 24h 计时 |
| 二次验证会话 | 默认 **2 分钟**内可复用；**不**重置 24h 计时 |

> 这保证了「生物识别不会把系统退化为单因素」。

### 9.3 Android 实现契约（Kotlin，待实现）

```kotlin
// 目标：AccountKey 存入 AndroidKeyStore，且要求用户认证
// 关键参数（安全相关，不可省略）：
//   KeyGenParameterSpec.Builder(alias, PURPOSE_ENCRYPT or PURPOSE_DECRYPT)
//     .setBlockModes(BLOCK_MODE_GCM)
//     .setEncryptionPaddings(ENCRYPTION_PADDING_NONE)
//     .setUserAuthenticationRequired(true)          // ← 绑定生物/PIN
//     .setUserAuthenticationParameters(0, AUTH_DEVICE_CREDENTIAL or AUTH_BIOMETRIC_STRONG)
//     .setIsStrongBoxBacked(true)                   // 优先硬件安全隔区
// 读取时用 BiometricPrompt 触发认证；认证失败需回退主密码（见 §9.2）
```

**必须遵守**
1. `setUserAuthenticationRequired(true)` 不得省略（否则等于明文存盘）。
2. 优先 `setIsStrongBoxBacked(true)`；设备不支持时降级并**记录**。
3. `delete` 必须调用 `KeyStore.deleteEntry` 并清空对应密文。
4. 不得把 AccountKey 复制到 SharedPreferences / 外部存储 / 日志。

### 9.4 iOS 实现契约（Swift，待实现）

```swift
// 目标：AccountKey 存入 Keychain，访问受生物识别保护
// 关键属性（安全相关，不可省略）：
//   kSecClass:            kSecClassGenericPassword
//   kSecAttrAccessible:   kSecAttrAccessibleWhenUnlockedThisDeviceOnly   // ← 不进 iCloud 备份
//   kSecAttrAccessControl: SecAccessControlCreateWithFlags(
//       nil, kSecAttrAccessibleWhenUnlockedThisDeviceOnly, .biometryCurrentSet, &err)
// 读取时用 LAContext.evaluatePolicy(.deviceOwnerAuthentication)
```

**必须遵守**
1. `kSecAttrAccessibleWhenUnlockedThisDeviceOnly`（**不得**用 `...AfterFirstUnlock` 或同步到 iCloud）。
2. `.biometryCurrentSet`：生物特征变更（新增指纹/面容）后旧条目自动失效。
3. 生物识别失败必须回退主密码（见 §9.2）。
4. ⚠️ iOS **无 FLAG_SECURE 对等能力**，防截图只能弱化处理并如实告知（ADR-009）。

### 9.5 Dart 侧桥接（骨架已生成）

`mobile/lib/platform/secure_store_channel.dart` 定义 `MethodChannel('fuxipass/secure_store')`，
方法与 Rust trait 一一对应：

| Dart 方法 | 原生参数 | 返回 |
| :-- | :-- | :-- |
| `store(id, bytes)` | `id: String, secret: ByteArray` | `null` |
| `load(id)` | `id: String` | `ByteArray?` |
| `delete(id)` | `id: String` | `null` |
| `isBiometricAvailable()` | — | `bool` |
| `authenticate(reason)` | `reason: String` | `bool` |

原生侧（Kotlin/Swift）实现该 channel 后，即可把 `CallbackSecureStore` 接到 Rust。
