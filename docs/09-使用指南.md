# FuxiPass 使用指南（PC 网页端）

> 适用当前状态：保险库位于 `~/FuxiPassVault/fuxipass.vault.db`，含 81 条账号。
> 本指南只讲**怎么用**，不涉及开发。

---

## 0. 一件事先记住

| 必须记牢 | 说明 |
| :-- | :-- |
| **主密码** | 你自己设的那个。忘记后只能用恢复密钥重置。 |
| **恢复密钥** | 一串 `XXXX-XXXX-…`（13 组）。**忘记主密码时唯一的救命稻草**，请离线保存。 |

> ⚠️ 主密码连续输错 **5 次会锁 5 分钟**（指数退避至 30 分钟上限）。**只锁定，不会删数据**，但别乱试。

---

## 1. 启动网页端（查看信息的主要方式）

打开终端，运行：

```bash
cd /home/yjj/FuxiPass
./target/debug/vault_web --db ~/FuxiPassVault/fuxipass.vault.db
```

看到以下输出即成功：

```
FuxiPass 本地验证界面
  数据库 : /home/yjj/FuxiPassVault/fuxipass.vault.db
  访问   : http://127.0.0.1:8787
```

然后**打开浏览器**访问：**http://127.0.0.1:8787**

> - 服务只监听本机（`127.0.0.1`），局域网其他设备访问不到。
> - **停止服务**：在该终端按 `Ctrl + C`。
> - 端口被占用时换一个：加 `--port 8888`。
> - **空闲自动锁定**：默认 **5 分钟**无操作自动锁定（服务端强制，浏览器关闭也会失效）。
>   调整：`--idle-timeout 60`（秒）；关闭（不推荐）：`--idle-timeout 0`。

## 2. 查看已保存的信息

### 2.1 解锁
在页面上输入**主密码** → 点「解锁」→ 进入主界面（应显示 81 条账号）。

### 2.2 查找
顶部搜索框支持模糊匹配，输入任一即可：
- 平台名：`建设` / `淘宝`
- 网址片段：`ccb` / `github`
- 账号片段：`zhangsan` / `202300732`

### 2.3 查看详情
点任意一张卡片，弹出详情页：

| 显示内容 | 说明 |
| :-- | :-- |
| 登录账号 / 网址 / 备注 | 直接显示（普通敏感级） |
| 登录密码 / 二级密码 / 支付密码 / 密钥 | **默认脱敏**（如 `88****`） |

### 2.4 查看密码明文（需二次验证）
点字段旁的「🔑 解锁查看」→ 弹窗要求**再次输入主密码** → 验证通过后显示明文。

> 这是**二次验证**：即使你已经解锁了应用，读支付密码这类高敏感字段仍需再确认一次。
> 验证会话有效期 **2 分钟**，超时需重新输入。

### 2.5 复制到剪贴板
- 普通字段（账号/网址/备注）：点「复制」→ 30 秒后自动清空剪贴板
- 高敏感字段：揭示后点「复制（高敏感）」→ 会先警告，确认后 30 秒自动清空

### 2.6 用命令行快速查看（不启动网页）
只列出**平台名与字段数量**（不显示任何密码）：

```bash
cd /home/yjj/FuxiPass
./target/debug/vault_cli list --db ~/FuxiPassVault/fuxipass.vault.db
```
会提示输入主密码。

## 3. 导入新的信息

### 方式一：网页端「导入文本」（批量，推荐）

适合把一大段旧记录（QQ 记事本、备忘录、微信收藏）一次导入。

1. 主界面点「**导入文本**」
2. 把内容粘贴进文本框
3. 点「**解析预览**」→ 系统自动识别出表格
4. 逐条核对/修改（可删掉不要的）
5. 点「**确认导入**」→ 输入主密码 → 完成

**支持的文本格式**（以下都能识别）：

```
# 这是注释行，会被忽略

[淘宝]
账号：tb_user
密码：Tb#2024
备注：常用

【京东】 账号：jd_user 密码：Jd#2024

网易邮箱
mailuser
Mail#2024
```

**可识别的字段标签**：

| 你要填的 | 可写的标签（任选，中英文均可） |
| :-- | :-- |
| 平台名 | `[平台]`、`【平台】`，或直接写在块首 |
| 账号 | `账号`、`帐号`、`用户名`、`username`、`account` |
| 登录密码 | `密码`、`登录密码`、`password`、`pwd` |
| 二级密码 | `二级密码`、`安全码` |
| 支付密码 | `支付密码`、`交易密码`、`银行卡密码` |
| 密钥 | `密钥`、`API Key`、`apikey`、`私钥`、`token` |
| 网址 | `网址`、`网站`、`url` |
| 备注 | `备注`、`说明`、`note` |

**多条之间**用空行，或 `---` / `===` / `***` 分隔。

> 解析不准的地方会打上黄色告警（如「缺少密码」），导入前可以手工改。

### 方式二：网页端「＋ 新增账号」（单条手工录入）

1. 主界面点「**＋ 新增账号**」
2. 填写表单（平台名必填，其余可空）
   - 分类可选：常用 / 金融银行 / 低频备用 / 社交
   - 密码字段会以圆点隐藏
3. 点「**保存**」

> 因为启用了高敏感字段保护，**新增含支付密码/密钥的账号时会要求输入主密码**。

### 方式三：命令行批量导入（适合大文件）

```bash
cd /home/yjj/FuxiPass
./target/debug/vault_cli import \
  --db ~/FuxiPassVault/fuxipass.vault.db \
  --text /path/to/你的文本.txt
```
会提示输入主密码；导入完成后打印成功条数。

## 4. 日常维护

### 4.1 备份（强烈建议定期做）

```bash
cd /home/yjj/FuxiPass
./target/debug/vault_cli export \
  --db ~/FuxiPassVault/fuxipass.vault.db \
  --out ~/FuxiPassVault/backup-$(date +%Y%m%d).json
```
会提示：**主密码** + **备份口令**（可设一个不同于主密码的口令）。

> 备份文件是**加密**的，里面没有明文；但**备份口令忘了就打不开**，请一并记牢。
> 网页端「设置 → 导出加密备份」也能做同样的事。

### 4.2 在新电脑上恢复

```bash
mkdir -p ~/FuxiPassVault && cd /home/yjj/FuxiPass
./target/debug/vault_cli import-backup \
  --db ~/FuxiPassVault/fuxipass.vault.db \
  --in /path/to/backup-20261008.json
```
会先让你**设置这台电脑的主密码**，再输入**备份口令**。

### 4.3 修改主密码

```bash
cd /home/yjj/FuxiPass
./target/debug/vault_cli change-password --db ~/FuxiPassVault/fuxipass.vault.db
```
依次输入：当前主密码 → 新主密码。数据不会重新加密（只换钥匙）。

### 4.4 忘记主密码 → 用恢复密钥重置

```bash
cd /home/yjj/FuxiPass && ./target/debug/vault_cli recover \
  --db ~/FuxiPassVault/fuxipass.vault.db
```
依次输入：恢复密钥 → 新主密码。

> 恢复密钥是你导入时打印机的那串 `XXXX-XXXX-…`。**必须离线保存好。**

### 4.5 删除某条账号

```bash
cd /home/yjj/FuxiPass
./target/debug/vault_cli delete --db ~/FuxiPassVault/fuxipass.vault.db --app 12306
```
（名称匹配多条时会拒绝执行，需写更精确的名称。）

### 4.6 忘记主密码 → 邮箱验证码找回（需先绑定）

> 前提：已按 4.7 完成**邮箱绑定**，且找回服务正在运行。

1. 打开网页端（解锁页）
2. 点「**忘记主密码？**」
3. **方式二：邮箱验证码找回**：
   - 填绑定时用的邮箱 → 点「① 发送验证码」
   - 输入收到的 6 位验证码 → 点「② 验证」
   - 填**恢复密钥** + **新主密码** → 点「④ 重置主密码」
4. 用新主密码登录即可（**数据不丢，旧密码立即失效**）

> 本地联调时验证码会直接显示在页面上（无需配置邮件服务器）；
> 生产环境应接入邮件/短信网关下发。

**两种找回方式都需要恢复密钥** —— 它才是解开数据的钥匙；
验证码只是第二因素（防止仅凭邮箱就能重置）。

### 4.7 邮箱绑定（可选）

绑定后，忘记主密码时可通过**邮箱验证码 + 恢复密钥**找回（两者缺一不可）。
服务端**只保存**不可逆联系方式哈希与加密套件，**无法解密**你的数据。

**第一步：启动找回服务**（另开一个终端）
```bash
cd /home/yjj/FuxiPass
./target/debug/recovery_service --port 8799 --db ~/FuxiPassVault/recovery.db
```
- `--db` 指定**持久化文件** → **重启服务不会丢绑定**（推荐）
- 传 `--db :memory:` 则用内存（重启丢绑定，仅临时用）
- 本地联调可加 `--dev-echo-code`：验证码直接显示在网页上（**生产勿用**）

服务端可在另一个终端查看运行状态：
```bash
watch -n 2 'curl -s http://127.0.0.1:8799/v1/health'
```

**第二步：启动网页端时指向它**
```bash
./target/debug/vault_web --db ~/FuxiPassVault/fuxipass.vault.db \
  --recovery-service http://127.0.0.1:8799
```

**第三步：在网页端绑定**
「设置」→「找回服务（邮箱绑定）」→ 填邮箱 → 点「绑定」→ 输入主密码 → 完成

> 未配置找回服务时，该区块会显示「未配置」，绑定入口自动隐藏。

### 4.8 网页端「设置」里还有什么

- **密码提示词**：设置后，解锁页会显示（⚠️ 明文保存，别写密码本身）
- **重新生成恢复密钥**：旧密钥立即失效，需要二次验证
- **隐私与合规**：数据概览、导出审计 CSV、删除全部数据（需确认短语+主密码）

### 4.9 网页端「审计」

记录「谁在什么时候看了/改了哪类字段」，**不含任何明文**，可按操作类型筛选、导出 CSV。

## 5. 常见问题

| 现象 | 处理 |
| :-- | :-- |
| 浏览器打不开 | 确认终端里的服务还在运行；确认端口未被占用（换 `--port 8888`） |
| 解锁提示密码错误 | 别连试 5 次！先用**恢复密钥**确认能进去，再想密码 |
| 提示「已锁定，剩余 N 秒」 | 等倒计时结束即可，**数据没丢** |
| 查看密码提示「需要二次验证」 | 这是正常设计，重新输入主密码即可 |
| 提示「会话因长时间空闲已自动锁定」 | 正常安全行为，重新输入主密码解锁即可 |
| 嫌自动锁定太快 | 启动时加 `--idle-timeout 900`（15 分钟） |
| 剪贴板里的密码没了 | 30 秒自动清空的正常行为 |
| 忘记备份口令 | 备份文件无法打开（但库本身不受影响） |

## 6. 安全提醒（重要）

1. **恢复密钥离线保存**（抄纸上放安全处）——它是忘记主密码时唯一的出路。
2. **高价值账号建议轮换密码**：`GitHub`、`银行`、`邮箱`（QQ/Outlook/交大）。
   你原来的明文清单里这些密码已暴露过。
3. **不要**把 `~/FuxiPassVault/fuxipass.vault.db` 上传到网盘或 Git 仓库。
4. 主密码**不要复用**你清单里出现过的任何密码。
5. 用完网页端记得 `Ctrl+C` 停止服务（虽然有 5 分钟自动锁定兜底）。
6. **不要把真实个人数据写进代码、测试或提交信息**——如果你的仓库是公开的，Git 历史会永久留存。
